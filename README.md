# Daily Word Ladder

A lightweight introduction to [Pooplely](https://pooplely.com/), a free
four-letter word ladder game.

The public site is hosted with GitHub Pages:

https://arthury1n.github.io/daily-word-ladder/

## Local preview

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Deployment

The site is plain HTML, CSS, and SVG. Publish the repository root from the
`main` branch through GitHub Pages.
